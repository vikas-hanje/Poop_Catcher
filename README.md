# Poop Catcher

Poop Catcher is a feed the toilet game. Use A-D or Arrow keys to move toilet and try to catch as many poops as you can. This game is built as a hobby project and has MIT License, so feel free to clone and customise.

## Tech Stack

- Python3 - Pygame

## Setup

Prerequisites:

- Python3 or equivalent installed on the computer.

Clone the repository:

    git clone(ssh) git@github.com:vikas-hanje/git-practice.git

    git clone(https) https://github.com/vikas-hanje/Poop_Catcher

    cd git-practice

Install dependencies:

    pip3 install -r requirements.txt
for windows

    pip install -r requirements.txt

Run the game:

    python3 main.py
for windows

    python main.py
